# Matrix Processing System

## Description

Matrix Processing System is a Java-based application that performs matrix addition and basic matrix analysis. The program accepts two matrices from the user, validates their dimensions, adds corresponding elements, and calculates row and column totals.

## Objectives

- Accept two matrices from the user.
- Validate matrix dimensions.
- Perform matrix addition.
- Display the resultant matrix.
- Calculate row totals.
- Calculate column totals.
- Demonstrate 2D arrays, Scanner, nested loops, methods, and operators.

## Features

- User input using Scanner
- Two-dimensional arrays
- Matrix dimension validation
- Matrix addition
- Resultant matrix display
- Row total calculation
- Column total calculation
- Separate methods for different operations

## Technologies Used

- Java
- Scanner
- 2D Arrays
- Nested Loops
- Methods
- Arithmetic Operators

## Project Workflow

1. Start the program.
2. Enter the dimensions of both matrices.
3. Validate the matrix dimensions.
4. Create the 2D arrays.
5. Enter the elements of both matrices.
6. Display both matrices.
7. Add corresponding elements.
8. Display the resultant matrix.
9. Calculate row totals.
10. Calculate column totals.
11. Display the final analysis.
12. End the program.

## Main Methods

### inputMatrix()

Accepts matrix elements from the user using Scanner.

### displayMatrix()

Displays the matrix using nested loops.

### validateDimensions()

Checks whether both matrices have the same dimensions.

### addMatrices()

Adds corresponding elements of the two matrices.

### rowTotals()

Calculates the total of each row.

### columnTotals()

Calculates the total of each column.
